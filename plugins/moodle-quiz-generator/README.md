# Moodle: quiz generator

Prepara i quiz Moodle di informatica (esercitazioni, verifiche, ripassi) con domande Cloze e CodeRunner JavaScript, SQL e PHP: scaletta e tracce nella dashboard «Bozze dei quiz», poi Moodle XML e backup `.mbz` da ripristinare.

Per cominciare: in chat «installa la dashboard dei quiz» (comando `installa-dashboard`), poi «Nuovo quiz» nella dashboard.

Mappe dei prerequisiti: in chat «installa l'editor delle mappe» (comando `installa-mappe`), poi «una mappa dei prerequisiti su…». Ogni mappa diventa un backup `.mbz` di un'attività Database in cui gli studenti spuntano ciò che sanno fare e il docente vede il riepilogo della classe.

Tracce di progettazione di database (quinte): in chat «installa la pagina delle tracce» (comando `installa-tracce`), poi «una traccia di progettazione su…». Preset di difficoltà, soluzione, Word della verifica con griglia e copia PDP, HTML per la descrizione di un Compito.

Correzione di una verifica svolta: nella dashboard «Correzione verifiche» → «Nuova correzione» si trascina l'Excel «Risposte» di Moodle (i nomi li toglie la pagina, nel browser), poi in chat «correggi la verifica …». Claude propone punteggi e commenti nella dashboard «Correzione verifiche» (una per tutte le verifiche, per domanda o per studente), da cui si copiano in Valutazione manuale. Durante la correzione controlla anche le possibili copiature: le segnalazioni solide stanno nel pannello «Copiature».

Installazione, percorso di un quiz e guida d'uso: README e GUIDA.md nella radice del repository.
