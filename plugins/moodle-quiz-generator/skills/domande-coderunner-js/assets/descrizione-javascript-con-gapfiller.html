Javascript (con gapfiller): domande a completamento. Lo studente riempie gli spazi vuoti di un programma JavaScript direttamente nell'editor. Il codice viene eseguito con Node.js su Jobe.

Come si scrive la domanda

Il codice con gli spazi vuoti si scrive nel campo Global extra. Ogni spazio è un segnaposto {[x]}, dove x è la larghezza in caratteri. Con {[20-40]} i due numeri sono la larghezza predefinita e quella massima; se il secondo numero (con il trattino) manca, lo spazio si allarga quanto serve.

Nel campo Answer si scrive l'elenco delle risposte corrette in formato JSON, nell'ordine in cui compaiono gli spazi. Esempio, con questo codice in Global extra:

let somma = {[3]};
for (let i = 1; i <= {[3]}; i++) {
    somma = somma + {[3]};
}
console.log(somma);

la risposta è ["0", "5", "i"] e l'output atteso 15.

Codice del test

Il codice scritto nel campo Test viene eseguito prima del codice completato dallo studente: serve a definire i dati. Esempio: in Global extra console.log({[8]}.length);, nel test let nomi = ["Anna", "Luca", "Sara"];, risposta ["nomi"], output atteso 3.

Input e numeri casuali

Come nel prototipo «Javascript (con prompt)»: nel campo Standard input un valore per riga per i prompt() (che restituiscono testo e non mostrano il messaggio nell'output) e, per Math.random(), questa sequenza fissa:

[ 0.15, 0.23, 0.52, 0.34, 0.75, 0.38, 0.62, 0.01, 0.29, 0.40,
  0.92, 0.54, 0.42, 0.09, 0.10, 0.07, 0.88, 0.46, 0.01, 0.21,
  0.17, 0.64, 0.06, 0.57, 0.25, 0.29, 0.81, 0.57, 0.02, 0.62,
  0.03, 0.38, 0.64, 0.75, 0.22, 0.49, 0.89, 0.92, 0.13, 0.72 ]

Ogni test riparte dalla posizione scritta nel campo Extra (predefinita 0). Il parametro {"random": [0.5, 0.1, 0.9]} nel campo Template params sostituisce la sequenza.

Output atteso e punteggio

Nel campo Expected output va l'output del programma con le risposte corrette. Il confronto è esatto (maiuscole, minuscole e spazi contano) e la domanda è corretta solo se tutti i test passano.
