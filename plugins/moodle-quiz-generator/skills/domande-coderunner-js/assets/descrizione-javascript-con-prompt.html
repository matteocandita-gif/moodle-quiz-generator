Javascript (con prompt): domande in cui lo studente scrive un programma JavaScript. Il codice viene eseguito con Node.js su Jobe. La funzione prompt() si usa come nel browser, ma legge i valori dallo standard input del test.

Input con prompt

Nel campo Standard input del test si scrive un valore per riga, nell'ordine in cui il programma li chiede. Il messaggio del prompt non compare nell'output. prompt() restituisce sempre testo: per fare calcoli serve Number().

Esempio di risposta:

const n = Number(prompt("Inserisci un numero"));
const m = Number(prompt("Inserisci un numero"));
const somma = n + m;
console.log(somma);

Per il test si scrive nel campo Standard input:

4
3

e nel campo Expected output: 7

Se il programma chiede più valori di quelli forniti, prompt() restituisce undefined. Nei cicli che si fermano con un valore speciale (per esempio STOP), l'ultima riga dello standard input deve essere quel valore, altrimenti il programma non termina.

Codice del test

Il codice scritto nel campo Test viene eseguito dopo la risposta dello studente, quindi può chiamare le funzioni che lo studente ha scritto. Esempio: lo studente scrive una funzione media(a, b); nel test si scrive console.log(media(4, 6)); e come output atteso 5.

Numeri casuali

Math.random() restituisce, uno dopo l'altro, i valori di questa sequenza fissa:

[ 0.15, 0.23, 0.52, 0.34, 0.75, 0.38, 0.62, 0.01, 0.29, 0.40,
  0.92, 0.54, 0.42, 0.09, 0.10, 0.07, 0.88, 0.46, 0.01, 0.21,
  0.17, 0.64, 0.06, 0.57, 0.25, 0.29, 0.81, 0.57, 0.02, 0.62,
  0.03, 0.38, 0.64, 0.75, 0.22, 0.49, 0.89, 0.92, 0.13, 0.72 ]

Per avere valori diversi tra un test e l'altro, nel campo Extra del test si scrive la posizione da cui partire (predefinita 0; arrivati in fondo la sequenza ricomincia). Esempio: con Math.floor(Math.random() * 6) + 1 due lanci danno 1 e 2 con Extra vuoto, 5 e 3 con Extra 4.

Parametri del template (campo Template params, in formato JSON)

  • {"test_prima": true}: il codice del test viene eseguito prima della risposta dello studente. Serve per preparare dati che lo studente usa. Esempio: nel test let voti = [6, 8, 7]; e lo studente calcola la media dell'array voti.
  • {"random": [0.5, 0.1, 0.9]}: sostituisce la sequenza dei numeri casuali con quella indicata, di qualsiasi lunghezza. Il campo Extra funziona allo stesso modo.

Da ricordare

  • Node stampa un array come [ 1, 2, 3 ], con gli spazi, in modo diverso dalla console del browser: conviene far stampare gli elementi con un ciclo o con join().
  • alert e document non esistono in Node: il codice che li usa dà errore.
  • I decimali si stampano come in JavaScript (0.1 + 0.2 dà 0.30000000000000004): con toFixed(2) l'output è prevedibile.
  • Il confronto con l'output atteso ignora maiuscole e differenze di spazi. Il punteggio è la somma dei test superati.
