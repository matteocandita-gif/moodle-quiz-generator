=== question prompt
=== name
S1 - Scrivere: lo sconto con la tessera
=== note
Scrittura completa con input. Tre test: con tessera, senza tessera, caso limite (prezzo 0).
=== questiontext
<p>La <strong>Libreria Pagina 42</strong> fa uno sconto del <strong>10%</strong> a chi ha la tessera. Scrivi un programma che chiede con <span style="font-family: monospace;">prompt</span> il <strong>prezzo</strong> del libro e poi se il cliente ha la <strong>tessera</strong> (risposta <span style="font-family: monospace;">si</span> o <span style="font-family: monospace;">no</span>), e stampa il prezzo da pagare nella forma:</p>
[[codice semplice]]
Da pagare: 18 euro
[[/codice]]
=== answer
let prezzo = Number(prompt("Prezzo del libro"));
let tessera = prompt("Hai la tessera? (si/no)");
if (tessera == "si") {
    prezzo = prezzo - prezzo * 10 / 100;
}
console.log("Da pagare: " + prezzo + " euro");
=== test
// Caso con tessera: 20 euro
=== stdin
20
si
=== test
// Caso senza tessera: 20 euro
=== stdin
20
no
=== test
// Caso con tessera: 15 euro
=== stdin
15
si

=== question prompt
=== name
S2 - Scrivere: somma fino allo zero
=== note
Ciclo con terminatore: l'ultimo valore dello standard input è sempre 0.
=== questiontext
<p>Scrivi un programma che chiede numeri con <span style="font-family: monospace;">prompt</span> finché non viene inserito <strong>0</strong>, poi stampa la somma dei numeri inseriti nella forma <span style="font-family: monospace;">Somma: 12</span>.</p>
=== answer
let somma = 0;
let numero = Number(prompt("Inserisci un numero (0 per finire)"));
while (numero != 0) {
    somma = somma + numero;
    numero = Number(prompt("Inserisci un numero (0 per finire)"));
}
console.log("Somma: " + somma);
=== test
// Tre numeri e poi 0
=== stdin
4
5
3
0
=== test
// Subito 0
=== stdin
0
=== test
// Numeri negativi
=== stdin
-2
10
0

=== question prompt
=== name
F1 - Scrivere: la funzione maggiore
=== note
Funzione: il codice dei test la chiama. Il primo test, mostrato come esempio, spiega la forma.
=== questiontext
<p>Scrivi la funzione <span style="font-family: monospace;">maggiore(a, b)</span> che <strong>restituisce</strong> con <span style="font-family: monospace;">return</span> il maggiore dei due numeri. Non stampare niente dentro la funzione: le chiamate le fanno i test.</p>
=== answer
function maggiore(a, b) {
    if (a > b) {
        return a;
    }
    return b;
}
=== test
// Il primo è maggiore
console.log(maggiore(10, 3));
=== test
// Il secondo è maggiore
console.log(maggiore(5, 7));
=== test
// Numeri uguali
console.log(maggiore(4, 4));

I dati arrivano dal test (test_prima): array diversi in ogni test.
=== questiontext
<p>L'array <span style="font-family: monospace;">voti</span> esiste già e contiene i voti di uno studente.
