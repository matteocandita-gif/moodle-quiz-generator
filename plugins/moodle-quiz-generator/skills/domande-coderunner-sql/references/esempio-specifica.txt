=== database libreria
CREATE TABLE Editori (
    IdEditore INT PRIMARY KEY,
    Nome VARCHAR(50) NOT NULL,
    Citta VARCHAR(30)
);
CREATE TABLE Libri (
    ISBN CHAR(13) PRIMARY KEY,
    Titolo VARCHAR(100) NOT NULL,
    Autore VARCHAR(50) NOT NULL,
    Prezzo DECIMAL(6,2),
    IdEditore INT,
    FOREIGN KEY (IdEditore) REFERENCES Editori(IdEditore)
);

=== question
=== name
L5 - B1 - Scrivere: i libri sotto i 10 euro
=== note
SELECT su una tabella: il test non aggiunge niente, si confronta il risultato.
=== questiontext
<p>Nel database della <strong>Libreria Pagina 42</strong> la tabella <strong>Libri</strong> ha la struttura</p>
<p>Libri (<u>ISBN</u>, Titolo, Autore, Prezzo, IdEditore*)</p>
<p>Scrivi la query che mostra <strong>titolo e prezzo</strong> dei libri che costano <strong>meno di 10 euro</strong>, dal più economico al più caro.</p>
=== answer
SELECT Titolo, Prezzo
FROM Libri
WHERE Prezzo < 10
ORDER BY Prezzo;

=== question
=== name
L5 - B2 - Scrivere: libri ed editori di Milano
=== questiontext
<p>Schema:</p>
<p>Editori (<u>IdEditore</u>, Nome, Citta)<br>Libri (<u>ISBN</u>, Titolo, Autore, Prezzo, IdEditore*)</p>
<p>Scrivi la query che mostra il <strong>titolo</strong> di ogni libro e il <strong>nome</strong> del suo editore, solo per gli editori di <strong>Milano</strong>, in ordine di titolo.</p>
=== answer
SELECT L.Titolo, E.Nome
FROM Libri L INNER JOIN Editori E ON L.IdEditore = E.IdEditore
WHERE E.Citta = 'Milano'
ORDER BY L.Titolo;
