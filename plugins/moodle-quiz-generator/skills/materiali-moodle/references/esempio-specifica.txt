=== question multichoice
=== name
L1 - B4 - Trova l'errore: UPDATE senza WHERE
=== questiontext
<p>Il gestore vuole abbassare a 12 euro il prezzo del solo libro <em>Il nome del vento</em>, e scrive:</p>
[[codice sql]]
UPDATE Libri SET Prezzo = 12.00;
[[/codice]]
<p>Che cosa succede?</p>
=== answer 100
Tutti i libri passano a 12.00 euro, perché manca la clausola WHERE
=== feedback
Esatto: senza WHERE l'UPDATE vale per tutti i record.
=== answer 0
MySQL segnala un errore di sintassi, perché UPDATE richiede sempre WHERE
=== feedback
No: la query è sintatticamente corretta, ed è proprio questo il pericolo.
=== answer 0
Viene modificato solo il primo record della tabella
=== feedback
No: SQL lavora su tutti i record che soddisfano la condizione, e qui la condizione non c'è.
=== answer 0
Non cambia nulla, perché non è indicato quale libro modificare
=== feedback
No: se non indichiamo quale libro, il DBMS li modifica tutti.
=== question truefalse
=== name
L1 - A2 - WHERE e ORDER BY
=== options
correct: false
=== questiontext
<p>In una SELECT la clausola ORDER BY va scritta prima di WHERE.</p>
=== feedback true
No: prima si filtrano i record con WHERE, poi si ordinano con ORDER BY, e nella query le clausole compaiono in quest'ordine.
=== feedback false
Esatto: ORDER BY viene dopo WHERE, perché si ordinano i record già filtrati.
